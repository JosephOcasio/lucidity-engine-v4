# ⚛️ Lucidity Engine v4.0
### Semantic Candidate-Signal Detection Platform

Lucidity uses **Sentence-Transformers (ML)** and **vector embeddings** to detect semantic similarity, clustering, and candidate signal-vs-noise patterns. These outputs are **modeled indicators**, not direct measurements of scientific rigor, truth, consciousness, causality, or admissibility.

## Evidence boundary

Lucidity is a soft semantic detector. It may generate candidate relationships for review, but it does not independently promote them into validated claims or governance decisions.

Under the current ATLAS/Tatertot architecture:

1. Lucidity produces candidate semantic signals.
2. The original source and representation remain preserved.
3. Candidate signals enter ATLAS as modeled or unverified evidence.
4. Appropriate ACE/ATLAS source, provenance, contradiction, identifiability, and domain gates evaluate the candidate.
5. Only evidence that survives the applicable gate profile may be promoted or used downstream.

Embedding similarity, conceptual density, shared wording, symbolic resemblance, or narrative coherence alone do **not** establish independent convergence.

## 🚀 Key Features
* **Semantic Analysis:** Uses `all-MiniLM-L6-v2` to model conceptual similarity beyond exact keyword matching.
* **Candidate Signal Detection:** Surfaces semantic patterns for downstream evidence-governance review.
* **Real-time Visualization:** Reactive Gradio dashboard showing modeled "Conceptual Density" over time.
* **Persistent History:** SQLite backend to track and log analysis results.
* **Modular Software Architecture:** Separated Engine, Strategy, and UI layers. This describes software organization, not scientific validation or production authorization.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **ML Library:** Hugging Face (Sentence-Transformers)
* **Frontend:** Gradio
* **Database:** SQLAlchemy / SQLite

## Claim boundary

This repository does not, by itself, establish that a detected semantic pattern is scientifically rigorous, causally real, independently corroborated, or safe to act on. Domain validation and consequential use remain governed by the appropriate ATLAS/ACE evidence and authority controls.
